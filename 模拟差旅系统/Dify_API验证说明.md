## 验收含义与下一步

`authentication=passed` 表示 `/info` 与 `/parameters` 成功响应，且实际应用名称与配置一致。`conversation=passed` 表示两轮都有非空 `answer`，并返回相同会话标识；仍需人工阅读报告中的回复，确认第二轮正确修改草稿。该检查不等于行程规则、提交成功／失败或完整业务链路通过。

此阶段使用 `blocking` 响应。流式展示、前端状态同步和异常提示可在助手页面阶段验证。

当前 Chatflow 仍使用原 Demo 数据，回复末尾仍包含“模拟权限及历史行程校验”的旧说明。后续接入本地接口时需要按已确定的普通员工、默认有权限和直接模拟提交结果的范围同步文案与节点。

下一条链路是 Dify Cloud 调用本地模拟差旅 API。云端不能直接访问本机 `127.0.0.1:8766`；需要单独确定可访问通道，再接城市、交通和创建接口。目前模拟服务仍只供本机访问。
